# docs/prompts/ — Operational prompts

Prompts used for structured AI-assisted project tasks. These are operational
tools, not frozen scientific artifacts.

| File | Description |
|---|---|
| `Prompt_LLM.md` | Preambolo operativo: instradamento per tipo di richiesta con i costi, regole di lettura economica, precedenze sui conflitti, vincoli invalicabili e verifiche di chiusura. Da citare quando si chiede una modifica. |
| `Questions_LLM.md` | Modalità sola lettura: si appoggia a `Prompt_LLM.md` e aggiunge l'instradamento fine nel piano della nuova fase, i tre registri, il limite dei confronti fra le due fasi e l'obbligo di segnalare le contraddizioni. |
| `PROJECT_HANDOFF_PROMPT.md` | Comprehensive handoff prompt for onboarding a new AI session to the project state |
| `CODEX_PROMPT_EXP3_CLOSE_AND_V2.md` | Operational prompt for Exp3 closure and Exp3v2 setup |
| `FoT_setup_prompt_server.md` | Server-side setup prompt for FoT experiment execution |
