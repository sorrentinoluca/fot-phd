# reproducibility/ — Phase A verification artifacts

Independent verification data for Phase A threshold calibration and
injection-time analysis. These files allow re-checking the frozen Phase A
pipeline outputs without re-running the full computation.

## Contents

| File | Description |
|---|---|
| `threshold_calibration_verification.json` | Verification data for threshold calibration reproducibility |
| `normal_5h_window_maxima_recalculated.csv` | Recalculated normal 5h window maxima for cross-check |

### injection_time/

Injection-time verification detail tables.

| File | Description |
|---|---|
| `injection_time_summary.csv` | Summary of injection-time verification across faults |
| `injection_time_window_scores.csv` | Per-window score details |
| `injection_time_active_variable_recurrence.csv` | Active variable recurrence patterns |
