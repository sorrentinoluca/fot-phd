# supporting_records/ — Provenance, narrative, and historical documents

Supporting material that documents how decisions were made, preserves provenance
chains, and records superseded designs. Not required for initial scientific review
or result verification.

## Subdirectories

### communication_characterization/

FoT communication payload analysis: byte/token counts of transmitted peer insights
and descriptive ratios.

| File | Description |
|---|---|
| `COMMUNICATION_PAYLOAD_REPORT.md` | Human-readable payload characterization report |
| `communication_payload_report.json` | Machine-readable payload data |

### historical/

Superseded design documents preserved for decision provenance.

| File | Description |
|---|---|
| `PHASE_B_EXPERIMENT_DESIGN.md` | Phase B experiment design spec V1 (pre-implementation, superseded by V2) |
| `PHASE_B_EXPERIMENT_DESIGN_V2.md` | Phase B experiment design spec V2 (superseded by frozen protocol) |
| `README_CODE_V2.md` | Historical code README draft |
| `docs/README.md` | Historical docs README draft |

### narratives/

Project-level narrative and synthesis documents.

| File | Description |
|---|---|
| `FOT_PROJECT_TECHNICAL_NARRATIVE.md` | Comprehensive technical narrative of the FoT project |
| `FOT_PROJECT_LLM_REFERENCE.md` | LLM reference guide for project context |
| `FOT_TEP_POC_FINAL_SYNTHESIS.md` | Final synthesis of the TEP proof-of-concept |
